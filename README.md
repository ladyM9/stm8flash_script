# stm8flash_script
Programming multiple STM8S001J3 MCUs at once using multiple STLinks with Python3 script

Project based on Raspberry Pi 4 Computer(Model 2) for uplouad programm on STM8s001J3.

Components for project
- Raspberry Pi 4
- STM8S001J3
- ST-Link
- USB Dock
- Led diodes
- Wires for breadboard
